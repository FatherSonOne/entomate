# Entomate contributor instructions

Use `C:/Dev/apps/entomate` as the primary local checkout on this machine. If a session starts in an Entomate checkout under `C:/Dev/sandbox`, switch to the Apps checkout unless the user asks to use the sandbox copy.

## Merge and deployment

When a change is ready to merge, ask the user to approve merging and deploying it. An explicit instruction to merge and deploy that change is already approval.

After approval, merge the approved scope, deploy it to the intended hosted services, and verify the deployed change before reporting completion. If a deployment or verification is blocked, report the blocker and which services are live.
