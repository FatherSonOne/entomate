### **Key Gemini API Workflows:**

1. **Real-time Transcription → Summary Pipeline**
    - Audio input → Gemini speech-to-text
    - Transcription → Gemini summarization prompt
    - Output → Action items, decisions, summary
2. **Context-Aware Q\&A ("Ask Assistant")**
    - User query + retrieved CRM context → Gemini
    - Gemini synthesizes answer from multiple sources
    - Response includes sources and confidence
3. **Sentiment Analysis \& Pattern Detection**
    - Transcript chunk → Gemini sentiment classification
    - Aggregate sentiment across meetings
    - Pattern matching for recurring themes
4. **Predictive Task Generation**
    - Raw transcript → Gemini task extraction
    - Task metadata (assignee, priority, due date) inference
    - Validation before CRM creation
