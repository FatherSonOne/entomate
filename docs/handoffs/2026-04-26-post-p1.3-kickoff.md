## Gotchas the previous session paid the cost on

- **PowerShell quoting hell.** When asking the user to run shell commands, default to `Invoke-RestMethod` with hashtables piped through `ConvertTo-Json`. Avoid bash heredocs and `\` line continuations.
- **OAuth-only accounts.** Don't suggest the Supabase password grant. Either run shell commands yourself with the user's access token, or have him paste the DevTools localStorage snippet.
- **Trailing-period URLs in webhook config.** A bare URL at the end of a sentence in markdown is fine, but if the user manually copies it from a sentence with a period, the period sneaks in. Be explicit when handing out URLs that need to be pasted into web forms.
- **Render free tier cold-spin-down.** First request after idle takes 30–60s. If a user-facing diagnostic depends on a request hitting the backend immediately, ping `/health` first to warm it.
- **`req.rawBody` is critical for Svix verification.** It's stashed by the `verify` callback on `express.json()` in `backend/server.js`. Don't add another body parser that consumes the stream first.
