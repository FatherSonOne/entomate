WHAT YOU'RE BUILDING (The 60-Second Version)
================================================================================

Entomate = AI Meeting Intelligence + Project Management + CRM Integration

FLOW:
  1. User records a meeting
  2. Gemini AI transcribes it
  3. Gemini summarizes and extracts action items
  4. Action items automatically sync to Logos Vision CRM
  5. Team notified in Pulse Chat
  6. Users can ask questions about the meeting anytime
  7. Automations run (deals updated, projects created, tasks assigned)

TIMELINE:
  Week 1-2: Recording + Transcription working
  Week 3-4: CRM sync + Chat notifications working
  Week 5-6: Projects + Ask Assistant working
  Week 7-8: Automations + Production deployment

TECH STACK:
  Frontend: React or Vue (your choice)
  Backend: Node.js or Python (your choice)
  Database: PostgreSQL
  AI Brain: Gemini API (Google) - free tier available
  Integrations: Logos Vision CRM API + Pulse Chat API
