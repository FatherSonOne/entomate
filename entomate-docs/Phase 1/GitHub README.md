# Entomate: AI-Powered Meeting Intelligence Platform

![Entomate Logo](https://via.placeholder.com/400x100?text=Entomate)

**Transform meetings into action. Connect your CRM. Empower your team.**

Entomate is an intelligent meeting assistant that automatically transcribes meetings, extracts action items, syncs data to your CRM, and keeps your team informed—all in real-time.

🎯 **Core Features**
- 🎤 Automatic meeting transcription with Gemini AI
- 📝 AI-powered summaries and key decision extraction
- ✅ Automatic action item creation and assignment
- 🔗 Native Logos Vision CRM integration
- 💬 Pulse Chat notifications and team updates
- 🤖 Ask your meetings questions (semantic search)
- 📊 Project management and task tracking
- ⚙️ Intelligent workflow automations

## Quick Start

### For Non-Developers (2 minutes)

1. **Get Gemini API Key:**
   - Go to [aistudio.google.com](https://aistudio.google.com)
   - Create free account
   - Click "Create API Key"
   - Save the key (you'll need it in setup)

2. **Clone & Setup:**
git clone https://github.com/yourorg/entomate.git
cd entomate
npm install
cp .env.example .env

Edit .env with your API keys
npm start

## Tech Stack

### Backend
- **Runtime:** Node.js 18+ or Python 3.10+
- **Framework:** Express.js (Node) or FastAPI (Python)
- **Database:** PostgreSQL 14+
- **AI:** Google Gemini API
- **Search:** pgvector (PostgreSQL extension)
- **Queue:** Redis (optional, for async tasks)

### Frontend
- **Framework:** React 18+ or Vue 3+
- **Build:** Vite or Next.js
- **Styling:** Tailwind CSS
- **State:** React Query or Pinia
- **Real-time:** WebSocket

### Infrastructure
- **Hosting:** AWS, Heroku, DigitalOcean, or self-hosted
- **Database:** PostgreSQL 14+
- **Storage:** S3 or GCS for audio files
- **Monitoring:** Sentry, DataDog (optional)

### External APIs
- **Gemini API** - Transcription & AI analysis
- **Logos Vision API** - CRM integration
- **Pulse API** - Chat integration

## Configuration

### Gemini API Setup

1. Go to [Google AI Studio](https://aistudio.google.com)
2. Sign in with Google account
3. Click "Create API Key" in left sidebar
4. Copy the API key
5. Add to `.env` as `GEMINI_API_KEY`
6. Test in AI Studio playground before coding

### Logos Vision CRM Integration

**Get from your CRM team:**
- API endpoint base URL
- API authentication key/token
- Task creation endpoint format
- Supported fields (title, description, assignee, due_date, custom fields)

**Then configure in `.env`:**
LOGOS_VISION_API_URL=https://api.logosvis.com
LOGOS_VISION_API_KEY=your_key_here

text

### Pulse Chat Integration

**Get from your Pulse team:**
- API endpoint base URL
- API authentication method
- Message creation endpoint format
- Channel structure
- User identification method

**Then configure in `.env`:**
PULSE_API_URL=https://api.pulse.com
PULSE_API_KEY=your_key_here

POST /api/meetings # Create/start recording
GET /api/meetings # List meetings
GET /api/meetings/:id # Get meeting details
PUT /api/meetings/:id # Update meeting
DELETE /api/meetings/:id # Delete meeting
POST /api/meetings/:id/process # Process uploaded audio

POST /api/meetings
{

"description": "Quarterly planning and goal setting",

"pulse_channel_id": "sales" // optional

text

## Performance

### Optimization Tips

1. **Database:** Index on `created_at`, `meeting_id`, `status`
2. **Caching:** Use Redis for frequently accessed data
3. **API Calls:** Batch requests to Gemini API
4. **Frontend:** Lazy load components, optimize images
5. **Search:** Use vector similarity (pgvector) for fast semantic search

### Monitoring

Monitor these metrics:
- Meeting processing time (target: < 2 min)
- API response time (target: < 1 sec)
- Search latency (target: < 500ms)
- Error rate (target: < 0.1%)
- API cost (monitor Gemini usage)

## FAQ

**Q: Can I use this with other CRMs?**
A: Phase 1 is Logos Vision only. Phase 2 will add Salesforce, HubSpot, etc.

**Q: How much does Gemini API cost?**
A: Free tier includes 15 requests/min. Production pricing based on usage (~$1-5/month for most teams).

**Q: Can I self-host?**
A: Yes! See [DEPLOYMENT.md](./docs/DEPLOYMENT.md) for self-hosting instructions.

**Q: Is there a mobile app?**
A: Currently web-only. Mobile app planned for Phase 2.

**Q: How is data stored?**
A: PostgreSQL with encryption at rest. Audio files stored in S3 (encrypted).
