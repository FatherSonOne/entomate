SECTION 3: TECHNICAL SETUP (DAY 1-3)
================================================================================

STEP 1: GET API KEYS (1 HOUR)

These are required. Do NOT skip this.

GEMINI API (5 minutes):
1. Go to: https://aistudio.google.com
2. Sign in with Google account
3. Click "Create API Key"
4. Copy the key
5. Save in password manager
6. Paste in: backend/.env → GEMINI_API_KEY=xxxxx

SUPABASE (15 minutes):
1. Go to: https://supabase.com
2. Click "Start your project"
3. Create account
4. Create new project (name: "entomate")
5. Wait for setup (~2 mins)
6. Go to: Settings → API Keys
7. Copy "anon public" key
8. Copy "Project URL"
9. Paste in backend/.env:
   → SUPABASE_URL=xxxxx
   → SUPABASE_ANON_KEY=xxxxx

CRM API (optional for Week 3, can do later):
- If HubSpot: Settings → Private Apps → Create key
- If Salesforce: Setup → Apps → OAuth 2.0 → Create connected app
- If Pipedrive: Company settings → API tokens

STEP 2: CREATE PROJECT FOLDER (5 minutes)

In terminal:
mkdir entomate
cd entomate
mkdir backend frontend docs

Initialize backend
cd backend
npm init -y
npm install express cors dotenv helmet morgan @google/generative-ai @supabase/supabase-js multer uuid

Create .env file
echo "GEMINI_API_KEY=your_key_here" > .env
echo "SUPABASE_URL=your_url_here" >> .env
echo "SUPABASE_ANON_KEY=your_key_here" >> .env
echo "NODE_ENV=development" >> .env
echo "PORT=3000" >> .env

Initialize frontend
cd ../frontend
npm create vite@latest . -- --template react
npm install axios moment

cd ..

SECTION 8: TROUBLESHOOTING
================================================================================

PROBLEM: "Gemini API not responding"

Solution:
1. Check API key is correct in .env
2. Go to https://aistudio.google.com
3. Verify API key is active
4. Check you haven't hit rate limit (free: 15 req/min)
5. Create new API key if needed
6. Restart backend (npm start)

PROBLEM: "Database connection failed"

Solution:
1. Check Supabase URL and key in .env
2. Go to Supabase dashboard
3. Verify project is "Running" (not paused)
4. Check internet connection
5. Test in browser: https://[your-url].supabase.co
6. Verify firewall not blocking connection

PROBLEM: "Microphone not working"

Solution:
1. Check browser permissions:
- Chrome: Settings → Privacy & security → Microphone
- Firefox: Preferences → Privacy → Permissions → Microphone
2. Allow microphone for localhost:5173
3. Test mic in system settings
4. Try different browser
5. Restart browser

PROBLEM: "Frontend can't connect to backend"

Solution:
1. Check backend is running: npm start (should show port 3000)
2. Check frontend .env has correct URL:
VITE_API_URL=http://localhost:3000
3. Check CORS is enabled in backend (should be)
4. Check firewall not blocking port 3000
5. Test in browser: http://localhost:3000/api/health

PROBLEM: "Tests failing"

Solution:
1. Check all tests run locally first
2. Verify test data exists in database
3. Check timing issues (sometimes tests need delays)
4. Run one test at a time to isolate issue
5. Read error message carefully (usually tells you what's wrong)

For more issues, see Quick Start Guide (File 5) "Troubleshooting" section.
